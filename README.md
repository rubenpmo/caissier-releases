# Caissier — téléchargements

Les installateurs de **Caissier pour Windows**, la caisse en ligne pour les commerçants suisses, avec impression directe sur les imprimantes de tickets réseau.

- Télécharger : [www.caissier.ch/telecharger](https://www.caissier.ch/telecharger)
- Guide : [Caissier sur un PC Windows](https://www.caissier.ch/docs/demarrer/windows)

Chaque version est publiée dans [Releases](../../releases). Ce dépôt ne contient que les fichiers d’installation ; le code de Caissier n’est pas public.
